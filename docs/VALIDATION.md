# Проверки версии 0.2.0 — 13 ноября 2026

## ПК

- 27 Python-проверок прошли на Arch Linux: очередь, квоты, повторные попытки, авторизация, паузы, сохранение сессии, UDP-поиск, Range, SHA-256, независимая история, запуск Qt и блокировка второго экземпляра.
- Реальные кодирования H.264, HEVC и AV1 проверены на локальных синтетических файлах. Проверка умного режима сравнивает SHA-256 самой сжатой видеодорожки до и после обработки: совместимая компактная дорожка сохраняется без перекодирования.
- Неизвестный битрейт аудио и некорректная частота кадров больше не вызывают падения обработки.
- Chromium: автоматическая очередь после подключения аккаунта, настройки, привязка телефона, поиск, закрепление, настоящий H.264 и компактная вёрстка. axe: 0 нарушений на четырёх проверенных экранах.
- Ранее подтверждено чтение персональной ленты после входа владельца и получение двух файлов реальным телефоном. Во время подготовки этой версии новые видео из интернета не скачивались; для проверок использованы локальные файлы.

## Android

- assembleDebug, assembleDebugAndroidTest и lintDebug прошли: 0 ошибок, 35 предупреждений Lint. Подавления ошибок не добавлялись.
- На отдельном эмуляторе выполнен настоящий код Repository: подключение, Wi-Fi-передача двух файлов, обложки, SHA-256, докачка Range, сохранение ключа в Android Keystore, позиции просмотра и плейлиста.
- Проверены поиск с опечаткой, фильтры длительности и ограничения количества/размера/свободного места.
- На APK 0.2 повторно подтверждены просмотр и переход ко второму файлу при отключённых Wi-Fi и мобильных данных, а также полноэкранный режим при повороте.

## Windows

Переносимый комплект содержит CPython 3.13, PySide6/Qt, Node 22, FFmpeg/ffprobe и APK. Под Wine проверены импорты Qt, Node, настоящее создание и обработка видео, SQLite, HTTP-сервер, выдача APK, подключение, Range, SHA-256, остановка передачи, консольный запуск, запуск pythonw без консоли и блокировка второго экземпляра.

В GitHub Actions предусмотрен запуск `scripts/verify_windows.py` на настоящем Windows runner. Результат конкретного запуска доступен во вкладке Actions; наличие workflow само по себе не означает успешную проверку.

## Ограничения проверки

Финальный APK этой версии проверен на эмуляторе, а не установлен удалённо на телефон владельца. Установка поверх прежней версии сохраняет данные при совпадении подписи. Выпускная APK подписана локальным debug-ключом; ключ в репозиторий не входит. APK из самостоятельных CI-сборок может иметь другую подпись.

Не проверены вручную TalkBack, все OEM-режимы энергосбережения, все Android-кодеки и домашние маршрутизаторы. Фоновые сроки WorkManager и неизменность YouTube не гарантируются. Нагрузка локальной сборки/эмулятора ограничена через cgroups и низкий приоритет.
