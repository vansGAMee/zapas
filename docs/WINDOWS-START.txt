ЗАПАС — БЫСТРЫЙ ЗАПУСК НА WINDOWS 10/11 (64 БИТ)

1. Нажми правой кнопкой на ZIP → «Извлечь всё».
2. Открой извлечённую папку и дважды нажми «Запустить.cmd».
3. Один раз войди в YouTube в открывшемся окне браузера.
4. В Запасе выбери «Телефон → Подключить»: QR откроет установку Android и подключение.

Python, FFmpeg, Node и Qt уже включены. Интернет нужен для первого входа и новых видео.
На ПК должен быть установлен Edge, Chrome или Chromium. ПК и телефон — в одной домашней сети.

Если телефон не видит ПК: дважды нажми «Настроить-сеть.cmd» и подтверди запрос Windows.
Помощник открывает только TCP 9473 и UDP 9474 для частной локальной сети.

Окно можно закрыть — Запас останется в трее. Полный выход: значок в трее → «Выйти».
Лимиты, качество, пауза и автозапуск — в настройках. Сохранённое видео работает без интернета.
Обновление: распакуй новую версию; медиатека хранится отдельно в %LOCALAPPDATA%\zapas.
