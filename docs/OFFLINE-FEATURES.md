# Запас 0.2: возможности и границы

Продукт: личная видеотека для дороги. Оформление использует знакомую структуру YouTube и компоненты Material 3, а не авторизацию от имени официального приложения.

| Возможность | Реализация |
|---|---|
| Рекомендации | Настоящая авторизованная главная YouTube на ПК, без ручного ввода ссылок |
| Офлайн-лента | Файлы, обложки, названия, длительность, канал |
| Автопродолжение | Media3, сохранение позиции, следующий непросмотренный ролик |
| Плеер | 0.5–2×, перемотка, повтор, масштаб, блокировка управления, таймер сна |
| Большой экран | Боковая навигация от 600dp; плеер с лентой от 840dp; автоматический полный экран на телефоне при повороте |
| Картинка в картинке | Android PiP; разрешение управляется Android |
| Умный поиск | Название/канал, одна опечатка в длинном слове; «короткие», «длинные», «досмотреть», «непросмотренные», «до 10 мин» |
| Медиатека | Локальные история, понравившиеся, смотреть позже, именованные плейлисты; выбор следующего видео |
| Поделиться | Передача сохранённого файла системным диалогом Android |
| Пополнение | Wi-Fi, LAN-поиск ПК, восстановление адреса, докачка, SHA-256; открытое приложение проверяет ПК каждые 30 секунд |
| Память | Число видео, общий бюджет, доля свободного места, резерв, лимит файла/длительности/сеанса, порядок загрузок |
| Очистка | Срок хранения просмотренного, защита закреплённого/плейлистов, выбор крупных файлов, удаление недокачанного |
| Пауза | Отдельно подготовка на ПК, передача с ПК и загрузки на телефоне; уже сохранённое доступно |
| Сжатие | H.264/HEVC/AV1, 480/720/1080p, режимы «Умно», «Быстрее», «Компактнее»; компактная совместимая дорожка копируется без потери качества |

Понравившиеся, плейлисты и история — локальные. Они не записываются в Google-аккаунт. Комментарии, публикация роликов, покупки, прямые эфиры, серверные рекомендации YouTube на телефоне, Cast и загрузка субтитров не реализованы. Онлайн-поиск по всему YouTube не подменяется поиском по сохранённой библиотеке. Это не полная реализация всех сервисов YouTube.

Исходные ориентиры: [Smart Downloads и лимиты памяти](https://support.google.com/youtube/answer/12002587?co=GENIE.Platform%3DAndroid&hl=en), [YouTube PiP](https://support.google.com/youtube/answer/7552722?co=GENIE.Platform%3DAndroid&hl=en), [Android PiP](https://developer.android.com/develop/ui/views/picture-in-picture), [привязка соединений к локальной сети Android](https://developer.android.com/reference/android/net/Network).
