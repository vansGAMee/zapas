# Интерфейс Запаса

Задача: дома подготовить запас, перед выходом проверить готовность, в дороге сразу открыть видео. Главный экран — настоящая медиатека, а не панель показателей. Внешняя опора — приложенный пользователем тёмный YouTube; собственный знак и название отличают Запас от официального продукта.

На Android используются `MaterialTheme.colorScheme` и штатные Material 3 компоненты; первичный тон светлее для M3 tonal-контраста. Есть тёмная и светлая темы. Roboto/system sans: заголовок страницы 28–30, название видео 15–16, метаданные 12–14. Без внешних запросов к веб-шрифтам.

## Структура

ПК: drawer → верхний поиск → заголовок/действие → готовность передачи → фильтры → сетка 16:9. Ширина даёт 2–4 колонки, компактное окно — rail и одна колонка. Видео не обводятся дополнительными карточками. Скругление обложки 12, информационных блоков 16, диалогов 24, кнопок 24.

Android: top app bar → офлайн-готовность → локальная лента → navigation bar. Главное действие на пустом экране — подключить ПК; после подключения — смотреть видео. В широком окне адаптивная сетка даёт несколько колонок. Плеер сворачивается в миниплеер; Android Back сохраняет пространственную логику.

Верхние разделы Android: Главная, Загрузки, Медиатека, Настройки. Фильтры меняют набор видео в текущем разделе. Параметры сжатия и памяти не конкурируют с просмотром на главном экране.

## Компоненты и поведение

- Filled button: основное действие; tonal/outlined: вторичное; text: контекстное.
- FilterChip: фильтрация видео и выбор качества, с явным selected.
- Modal bottom sheet: действия над роликом. AlertDialog: подтверждение удаления/отключения.
- Switch: настройки применяются сразу; Slider: лимит сохраняется после отпускания.
- Snackbar: результат изменения; ошибки формы остаются рядом с полем.
- Готовность отмечена иконкой и текстом, а не только зелёным цветом.

## Состояния

Пустая медиатека объясняет три шага подключения. Нет результатов поиска — предлагается изменить запрос. Очередь показывает загрузку, сжатие, прогресс и ошибку с повтором. Нет сети — остаются локальная лента и плеер; автоматическая синхронизация ждёт. Полный лимит объясняется как ожидание места. Повреждённый файл не становится доступным для просмотра.

## Доступность и отклонения

Android: стандартные компоненты M3, touch targets 48dp, системные insets, текст масштабируется, иконки действий подписаны. ПК: видимый keyboard focus, семантические кнопки/диалоги, поиск по `/`, `Esc` закрывает диалог, учтён `prefers-reduced-motion`. Картинки декоративны рядом с названием. Основное действие имеет контрастный тёмный текст на красном фоне.

YouTube-подобная плотность и нейтральные тёмные поверхности — осознанная адаптация под запрос. Веб-интерфейс использует собственные CSS-компоненты с M3-семантикой; он не объявляется официальной реализацией Material Web. Android использует `androidx.compose.material3`.

Проверка TalkBack, крупного системного шрифта и поведения на физическом телефоне должна проводиться на реальном устройстве. Автоматический веб-аудит эту проверку не заменяет.
