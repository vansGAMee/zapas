# Запас

Твои рекомендации YouTube автоматически становятся офлайн-видеотекой. ПК готовит видео; Android забирает их дома по Wi‑Fi. В дороге лента, обложки, поиск и следующий ролик работают из памяти телефона.

## Скачать

[Сборки для Windows и Android](https://github.com/vansGAMee/zapas/releases). Windows: распаковать ZIP целиком → `Запустить.cmd`. Android: установить APK. Arch Linux: исходники и `./start.sh`.

Версия 0.2.0 — предварительный выпуск. [Проверки и ограничения](docs/VALIDATION.md). Обновляй Android из одного источника: APK из отдельной CI-сборки может иметь другую подпись.

## Первый запуск

1. Запусти **Запас** на рабочем столе или `./start.sh`.
2. Один раз войди в аккаунт в открывшемся обычном окне YouTube. Пароль вводится на сайте Google; приложение его не получает.
3. Установи **Запас.apk** из папки `Desktop/Запас` на Android 8.0+.
4. Подключи устройства к одной домашней сети. На ПК: **Телефон → Подключить**. В Android: **Настройки → Подключить компьютер**. ПК находится автоматически; введи одноразовый код. QR открывает обычную локальную страницу: можно установить APK и перенести адрес с кодом в приложение.

Дальше выбирать ролики, вставлять ссылки и держать открытой главную YouTube не нужно. При первом запуске включается автозапуск ПК; он отключается в настройках. Закрытое окно остаётся в трее. Полный выход — **Выйти** в меню трея.

## Что происходит само

- Раз в 6 часов ПК читает твою главную в отдельном браузерном профиле. Дополнительных подгрузок не больше трёх, с паузами. Уже скачанное и просмотренное пропускается.
- Видео готовятся последовательно, с низким приоритетом и двумя потоками кодировщика. Загрузка по умолчанию ограничена 4 МиБ/с.
- По умолчанию ПК держит до 100 роликов и 16 ГБ; телефон — до 50 роликов и 8 ГБ. Лимиты настраиваются. Фактическое количество зависит от длительности и места.
- Android проверяет домашний ПК примерно раз в 15 минут, когда позволяют Wi‑Fi, заряд и ограничения системы. Первая синхронизация запускается сразу после привязки.
- После просмотра телефон освобождает место при синхронизации. ПК тоже убирает просмотренное, когда его подтвердили все активные телефоны. Закреплённое сохраняется.
- Передача продолжается с места обрыва. Перед публикацией проверяются размер и SHA‑256. Повреждённый ролик не останавливает остальные.
- Обычные ошибки ПК повторяются с задержкой, максимум три попытки на ролик за сутки. Недоступное и приватное пропускается. Стримы и премьеры ждут завершения; видео длиннее 6 часов пропускаются.

Перед выходом можно нажать **Синхронизировать** на телефоне и проверить число видео «на телефоне». Android может задерживать фоновую работу; точное время запуска не гарантируется.

## Сжатие

| Профиль | Верхнее разрешение | H.264 CRF | Аудио AAC |
|---|---:|---:|---:|
| Экономный | 480p | 29 | 64 кбит/с |
| Баланс | 720p | 25 | 96 кбит/с |
| Качество | 1080p | 21 | 128 кбит/с |

H.264 — начальный совместимый вариант. Есть HEVC и AV1; для них нужна поддержка телефоном. Частота ограничена 30 fps, разрешение не увеличивается. Выдача — MP4/AAC с faststart. Профиль с телефона передаётся ПК при синхронизации и действует на следующие видео общей медиатеки. Готовые файлы не перекодируются автоматически.

Размер зависит от исходного кодирования, движения и шума. Сильное уменьшение любого файла без изменения качества не гарантируется. Оригиналы личных файлов не удаляются.

## Аккаунт и ограничения YouTube

Вход выполняется в отдельном профиле установленного Chrome, Chromium или Edge. Основной профиль браузера не меняется. Пароли и cookies Google не передаются yt-dlp: публичные видео скачиваются без входа. Приложение не ставит лайки, не пишет комментарии и не меняет историю YouTube. Офлайн-история отдельная.

По умолчанию — до 80 попыток загрузки за скользящие 24 часа, между роликами пауза 45–90 секунд. Повторное нажатие кнопки не отменяет паузы. При HTTP 403/429, капче или запросе подтверждения автоматика останавливается на 12 часов. Решения проверок, смены IP и ротации аккаунтов нет.

Эти меры ограничивают нагрузку, но не гарантируют отсутствие блокировок. [Условия YouTube](https://www.youtube.com/static?template=terms) ограничивают автоматизированный доступ и скачивание. При изменениях сайта или истечении сессии может понадобиться обновление приложения либо повторный вход.

## Сеть и данные

ПК должен быть включён, Запас запущен, порт TCP 9473 доступен в домашней сети. Гостевая Wi‑Fi с изоляцией клиентов мешает обмену. Поиск ПК работает через UDP 9474. При смене IP телефон находит прежний ПК по идентификатору. HTTP идёт через физическую сеть, включая Wi‑Fi при активном VPN; блокирующий LAN VPN или гостевая сеть могут помешать. При запрете broadcast остаётся ручной адрес.

ПК: `~/.local/share/zapas` в Linux, `%LOCALAPPDATA%\zapas` в Windows. Здесь SQLite, видео, обложки и отдельный профиль YouTube. Android хранит данные во внутренней папке, ключ устройства зашифрован через Keystore; резервное копирование отключено.

Код подключения одноразовый на 5 минут, с ограничением неверных попыток. У каждого устройства отдельный ключ; на ПК хранится его хеш. Устройство можно отозвать. Передача — HTTP внутри доверенной локальной сети; не открывай порт в интернет. TLS в 0.2 не реализован.

## Запуск и сборка

На этом Arch Linux окружение подготовлено: `./start.sh`. Нужны FFmpeg/ffprobe, Node.js либо Deno и Chrome/Chromium/Edge. Python-зависимости — `desktop/requirements.txt`.

Windows 10/11 x64: переносимая сборка `Запас-Windows` содержит Python, Qt, FFmpeg, ffprobe и Node. Распакуй всю папку и запусти `Запустить.cmd`. Chrome/Edge используется уже установленный. Если брандмауэр мешает телефону, `Настроить-сеть.ps1` создаёт правила только для частной локальной сети. Проверка через Wine не заменяет испытание на настоящей Windows.

Windows: исходный вариант `start.bat` требует Python 3.11+, FFmpeg/ffprobe и Node.js/Deno в PATH. `.github/workflows/build.yml` запускает сборку и проверку переносимого комплекта на Windows через `scripts/build_windows_portable.py`; сведения о выполненных проверках — в `docs/VALIDATION.md`.

Без окна: `PYTHONPATH=desktop .venv/bin/python -m zapas --headless`. URL в выводе содержит административный ключ — не публикуй его. Первый вход YouTube выполняется через обычное окно приложения.

Проверки:

```bash
.venv/bin/python -m pytest -q
npm ci --ignore-scripts
npm run test:browser
cd android
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew :app:assembleDebug :app:lintDebug --no-daemon
```

Результаты: [docs/VALIDATION.md](docs/VALIDATION.md). Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Оформление: [DESIGN.md](DESIGN.md).

## Обновление 0.2

[Полная таблица возможностей](docs/OFFLINE-FEATURES.md). В Android настройки разделены на «Память», «Скачивание», «Видео», «Вид». Умный режим сжатия сохраняет уже компактную совместимую видеодорожку, что экономит время и не увеличивает её размер повторным кодированием. При нехватке памяти можно поставить передачу на паузу и выбрать крупные файлы для удаления; уменьшение бюджета само по себе не удаляет непросмотренное.
